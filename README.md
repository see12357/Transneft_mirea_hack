

# Цифровой консультант ПАО «Транснефть»

Этот репозиторий содержит решение для хакатона «Цифровая весна» от ПАО «Транснефть». Проект представляет собой полноценного RAG-ассистента, способного отвечать на вопросы о компании на основе предоставленной базы знаний, а также взаимодействовать с пользователем с помощью голоса и анимированного аватара.

### Ключевые возможности
- Диалог в режиме вопрос-ответ на основе документа `.docx`.
- Голосовой ввод сообщений (Speech-to-Text на базе `Whisper`).
- Голосовое воспроизведение ответов бота (Text-to-Speech через API браузера).
- Анимированный 2D-аватар, реагирующий на состояние диалога.
- Защита от базовых промпт-инъекций и естественное ведение диалога.
- История диалога для каждого пользователя с использованием Redis.
- Полностью контейнеризированное решение, разворачиваемое через Docker Compose.

- **Бэкенд:** FastAPI, Python 3.10, LangChain, PyTorch, Transformers
- **Фронтенд:** React, Material-UI, Nginx
- **AI/ML:**
  - **LLM:** `gemma3:4b-it-qat` (через Ollama)

  - **Векторная база:** FAISS
- **Инфраструктура:** Docker, Docker Compose, Redis

## ⚙️ Установка и запуск

Процесс запуска состоит из двух обязательных этапов: **локальная подготовка** и **запуск в Docker**.

### Этап 1: Локальная подготовка (создание векторной базы)

Этот этап необходимо выполнить **один раз** перед первым запуском Docker. Он создает векторный индекс (базу знаний), который затем будет использоваться бэкенд-сервисом.

#### 1.1 Установка зависимостей
Сначала нужно установить все Python-библиотеки на вашу локальную машину.

1.  Создайте и активируйте виртуальное окружение:
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    cd backend
    ```
2.  Установите зависимости из `requirements.txt`:
    ```bash
    pip install -r requirements.txt
    ```

#### 1.2 Создание FAISS-индекса
Скрипт `indexing.py` преобразует исходный `.docx` документ в векторную базу.

1.  **Подготовка:** Поместите ваш исходный документ `Реестр данных... .docx` в папку `backend/data/`.
2.  **Запуск индексации:**
    ```bash
    python backend/indexing.py
    ```
    - Процесс может занять **3-10 минут** на CPU, так как используется семантическое разделение на чанки.
    - После успешного выполнения в папке `backend/data/` появится директория `faiss_index_gemma`. **Не удаляйте ее**, она нужна для работы Docker-контейнера.

### Этап 2: Запуск проекта через Docker Compose

После того как векторная база создана, можно запускать всю систему.

#### 2.1 Конфигурация
1.  **Предварительные требования:**
    - Установленный [Docker](https://www.docker.com/get-started/)
    - Установленный [Docker Compose](https://docs.docker.com/compose/install/)

2.  **Токен Hugging Face:**
    - Получите токен доступа с правами на чтение (`read`) в настройках вашего профиля на [huggingface.co](https://huggingface.co/).
    - В корне проекта создайте файл `.env` и добавьте в него ваш токен:
      ```
      HF_TOKEN=hf_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
      ```
    - Файл `.env` уже находится в `.gitignore`, чтобы предотвратить утечку токена.

#### 2.2 Запуск
1.  Находясь в корневой папке проекта, выполните команду:
    ```bash
    docker-compose up --build -d
    ```
    - **Внимание!** Первый запуск будет долгим (15-40 минут), так как будут скачиваться все AI-модели (~20-25 ГБ). Последующие запуски будут быстрыми.

2.  **Проверка статуса:**
    Следите за логами бэкенда. Когда увидите сообщение `Сервер готов к работе`, система запущена.
    ```bash
    docker-compose logs -f backend
    ```

3.  **Доступ к приложению:**
    - **Фронтенд:** Откройте в браузере `http://localhost`
    - **API бэкенда (документация):** `http://localhost:8000/docs`

4.  **Остановка проекта:**
    ```bash
    docker-compose down
    ```

## 🔬 Работа с бенчмарком (`ev.py`)

Скрипт `ev.py` предназначен для оценки качества RAG-системы без использования Docker.

- **Цель:** Прогнать набор вопросов из `benchmark.csv` и рассчитать метрики качества.
- **Подготовка:**
    1.  Убедитесь, что вы выполнили **Этап 1** (локальная подготовка) и у вас есть FAISS-индекс в `backend/data/faiss_index_gemma`.
    2.  Убедитесь, что файл `benchmark.csv` находится в папке `backend`.
    3.  Установите и запустите [Ollama](https://ollama.com/) на вашем компьютере.
    4.  Скачайте необходимую модель в Ollama:
        ```bash
        ollama pull gemma3:4b-it-qat
        ```
- **Запуск:**
    ```bash
    python backend/ev.py
    ```
    Скрипт выведет в консоль рассчитанные метрики.
